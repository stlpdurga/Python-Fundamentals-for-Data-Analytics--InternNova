# Python-Fundamentals-for-Data-Analytics--InternNova
# InternNova Week 1

## 📌 Overview

This repository contains my Week 1 internship tasks focused on **Python Fundamentals for Data Analytics**.

The tasks cover basic Python concepts such as variables, data types, operators, conditional statements, loops, functions, strings, collections, file handling, and a mini project.

## 🎯 Objectives

- Understand the fundamentals of Python programming.
- Work with different variables and data types.
- Perform arithmetic operations using Python operators.
- Use conditional statements for decision-making.
- Use loops for repetitive tasks.
- Create and use user-defined functions.
- Work with strings and Python collections.
- Perform basic file handling operations.
- Build a simple Student Record Management System.

## 📂 Tasks

| Task | Topic | Description |
|------|-------|-------------|
| Task 1 | Python Basics | Basic input, output, and formatted printing |
| Task 2 | Variables & Data Types | Integer, float, string, and Boolean data types |
| Task 3 | Operators | Arithmetic operations using Python |
| Task 4 | Conditional Statements | Grade calculation using conditions |
| Task 5 | Loops | `for` and `while` loops |
| Task 6 | Functions | User-defined functions for calculations |
| Task 7 | Strings & Collections | Strings, lists, tuples, dictionaries, and sets |
| Task 8 | File Handling | Creating, writing, reading, and displaying a text file |
| Task 9 | Mini Project | Student Record Management System |
